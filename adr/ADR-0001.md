# Context

The order service must notify inventory and billing without waiting for each consumer to respond. The current synchronous integration couples availability and release schedules.

# Decision

We will publish order lifecycle events to Kafka through the event gateway. Consumers will process events independently and track offsets for replay.

# Consequences

Services can scale and deploy independently, and failed consumers can recover by replaying events. The team must operate the broker and account for eventual consistency.
