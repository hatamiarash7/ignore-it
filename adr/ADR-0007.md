# Context

The document API stores uploaded files on local disks. Files are not available to other instances, and disk capacity is difficult to scale safely.

# Decision

Uploaded documents will be stored in a private S3-compatible object store. The API will keep object identifiers and metadata in its relational database.

# Consequences

Instances can scale without sharing local storage, and object retention can be managed separately. The service must handle storage outages, access policies, and lifecycle rules.
