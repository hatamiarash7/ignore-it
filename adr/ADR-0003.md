# Context

Builds currently depend on the host environment, producing differences between developer machines and production servers.

# Decision

All deployable services will be packaged as OCI-compatible container images built from reviewed Dockerfiles.

# Consequences

The same artifact can be promoted between environments, improving reproducibility. Image scanning, registry retention, and base-image updates become ongoing responsibilities.
