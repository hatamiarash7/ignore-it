# Context

External partners connect directly to internal services, creating inconsistent rate limits and making API changes difficult to coordinate.

# Decision

Partner traffic will enter through a dedicated gateway. Public endpoints will be documented with OpenAPI and versioned independently from internal services.

# Consequences

Authentication, throttling, and API visibility can be managed centrally. The gateway adds a network dependency and requires a clear process for deprecating versions.
