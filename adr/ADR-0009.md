# Context

Nightly report generation runs on a shared virtual machine with manual recovery steps and limited visibility into failures.

# Decision

Scheduled report generation will run as Kubernetes CronJobs with explicit resource limits, retry policies, and centralized logs.

# Consequences

Jobs gain consistent scheduling and failure visibility, and can be scaled independently. Cluster capacity and idempotent report generation must be monitored.
